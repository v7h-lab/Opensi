# Cortex Ops Intake

A simple, client-side intake page for orders, support tickets, and invoices. It categorizes each item, suggests a next action, and keeps a timestamped activity log in the visitor’s browser. No server, login, dependencies, or build step required.

## Run locally

Open index.html in a browser, or serve this folder with any static file server.

## Deploy on Vercel

Import this repository in Vercel. Set the project root to the repository root and select Other as the framework preset. Leave the build and install commands blank and set the output directory to the repository root (.). Vercel serves index.html as the site entry point. Connect the repository to a Vercel project to enable automatic deployments on future pushes.
